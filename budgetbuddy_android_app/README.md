# BudgetBuddy Android App

BudgetBuddy is a Kotlin-based Android application that helps users manage and track daily expenses with a minimal and modern design. It uses an offline-first architecture with Room for local storage.

## Key Features (initial scaffold)
- Single-activity architecture with BottomNavigation
- Fragments for Dashboard, Add Expense, and Reports
- Material3 light theme using provided colors (primary: #2D9CDB, secondary: #56CCF2, accent: #27AE60)
- Room ORM scaffolding (entities, DAO, database, repository) for offline-first

## Build and Run
- Build: `./gradlew build` (from app root) or `bash ../../gradlew build` (from repo root via shim)
- Install debug: `./gradlew :app:installDebug`

## Icons
Adaptive icons are defined in mipmap-anydpi-v26. Density-specific PNGs are typically generated by Android Studio; placeholders are present here for CI-only environments.
